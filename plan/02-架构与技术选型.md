# plan/02 架构与技术选型

## 1. 技术选型

| 决策 | 采纳 | 弃选项与弃因 |
| --- | --- | --- |
| 实现语言 | Python ≥3.8 **纯标准库**（`csv`/`json`/`datetime`/`statistics`/`heapq` 等），零第三方依赖 | PM4Py（重依赖链、与零 CDN/零上传定位冲突，D3）；Node 实现（本机与 CI 双解释器矩阵用 Python 更稳） |
| 布局计算位置 | **Python 侧确定性计算节点坐标**（分层布局），坐标随 JSON 数据内嵌进 HTML | 浏览器 JS 力导向（无种子不可复现，D2）；JS 侧重算布局（计算语义散落两处，违背"数字全部由确定性代码产出"） |
| HTML 内嵌 JS 角色 | **只做表达层**：消费预计算好的坐标/频次/统计，负责悬停/点击交互 | JS 内重算任何数字（违背"模型与前端都不产出频次/fitness/坐标"纪律） |
| 交付形态 | SKILL.md + 源码包（纯标准库，clone 即用）+ 单文件 HTML 产物 | wheel/exe 打包（首期不承诺，见 plan/06 边界） |
| 测试框架 | pytest（唯一 dev extra） | unittest（断言写法冗长，pytest 是方法论既有口径） |

## 3. 确定性策略（全项目单点纪律）

1. **禁随机、禁时钟**：挖掘/布局/渲染代码路径不读系统时间、不用 stdlib `random`；合成日志生成器用自研确定性 RNG（splitmix64，固定 seed）。
2. **排序键显式**：变体 Top-N = 频次降序、并列按活动序列字典序；DFG 节点/边输出一律按键排序，杜绝 set/dict 迭代序进入产物。
3. **序列化参数冻结**：一切 JSON 落盘 `json.dumps(sort_keys=True, ensure_ascii=False, indent=2)` + LF + 结尾换行；HTML 落盘 LF、UTF-8 无 BOM。
4. **字节级双跑断言**：同输入两次渲染 HTML 逐字节一致（`--check` 通路 + 守门测试两层：冻结产物形态 + 重生成比对）。
5. **分位数算法固定**：等待时长/案例时长分位 = 线性插值法，写进代码注释与 README。
6. **零外链硬断言**：`render` 出口常驻 `assert_no_external_resources`（禁 `http://`/`https://`/`//` 外链、禁 CDN 域名），非仅测试期验一次。

## 4. 分层与依赖方向

```
logio ──▶ mining ──▶ layout ──▶ render
  └──────────┴──────────┴──────▶ cli（编排 + 退出码契约）
tools/gen_synthetic_log.py ──▶ data/（冻结产物）
tests/（消费 data/ 冻结产物 + 重生成比对）
```

- 依赖单向，render 只消费上游 JSON、零判定逻辑。
- **退出码契约**（骨架期即锁，锁进测试）：`0` 成功；`2` 用法/输入错误（文件不存在、schema 校验失败）；`3` 阶段未就绪（骨架期未实现模块显式报"未就绪"，不伪造空结果；模块落地后该语义整项退役，走 K 退役流程：常量→CLI→测试→文档→决策记录五处同步）。
- **编码守卫**：所有可执行入口（cli + tools/）挂 `_ensure_utf8_stdio()`（按 `stream.encoding` 探针 reconfigure），CI env 设 `PYTHONUTF8=1`。
